# Healthcare Database Management System

A relational healthcare database designed and implemented in MySQL,
covering database requirements analysis, ER modelling, normalisation,
SQL analytics and role-based access control.

## Project Overview

This project designs a centralised relational database for a fictional
healthcare organisation to manage patients, doctors, departments,
appointments, medical records, prescriptions and staff.

The database was designed from requirements analysis through conceptual,
logical and physical modelling before being implemented in MySQL.

## Key Features

- Relational database design
- Conceptual, logical and physical ER modelling
- Normalisation to Third Normal Form (3NF)
- Primary and foreign key constraints
- Multi-table JOIN queries
- Aggregation and GROUP BY
- CASE statements
- Subqueries
- SQL window functions
- Database views
- CRUD operations
- Role-based access control (RBAC)
